# TUGAS PENGENALAN HTML
## Studi Kasus: Halaman Berita Sederhana
Buatlah sebuah halaman web sederhana menggunakan HTML dengan studi kasus “Halaman Berita”. Buat sebuah berita dengan topik bebas, misalnya berita kampus, teknologi, olahraga, pendidikan, atau lingkungan. 

Halaman berita minimal memuat **judul berita, nama penulis, tanggal publikasi, gambar berita, paragraf isi berita, subjudul, hyperlink sumber berita, daftar informasi terkait, dan tabel data sederhana**. 

Gunakan tag HTML dasar yang telah dipelajari, seperti **html, head, title, body, heading, paragraph, image, hyperlink, list, dan table**. 

Tidak diperbolehkan menggunakan CSS atau JavaScript, karena tugas ini berfokus pada pengenalan struktur dan elemen dasar HTML.

## Ketentuan Pengumpulan
Kumpulkan tugas dalam 1 file PDF yang berisi identitas mahasiswa (Nama, NIM, dan Kelas), screenshot hasil halaman berita pada browser, serta screenshot/source code HTML yang dibuat. File PDF diberi nama dengan format **NIM_Nama_TugasHTML.pdf**.
